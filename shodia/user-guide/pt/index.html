Shodia · Guia do utilizador

Guia do utilizador

O Shodia torna simples manter um diário de treino completo e fiável e entregar os registos quando necessário.

Registar uma sessão

Adicione uma sessão e registe o essencial: arma, munições, distância, locais de impacto e pontuações. As sessões recebem uma marca temporal e são guardadas localmente.

Acompanhar objetivos

Defina o seu próprio objetivo de visitas. O Shodia mantém uma contagem atualizada para saber sempre como está a progredir. Confirme os requisitos de licença aplicáveis junto da autoridade competente. Consulte Exclusão de responsabilidade para conhecer os limites desta função.

Exportar registos

  • PDF — modelos específicos por país para um resumo de treino que pode partilhar com autoridades ou instrutores. Confirme com o destinatário se o resumo é aceite para o fim pretendido.
  • CSV — todo o seu histórico para análise pessoal, sem dependência da aplicação.

As exportações são geradas a pedido e partilhadas apenas com os destinos que escolher.

Bloquear o diário

Ative o bloqueio biométrico ou por PIN para que só o utilizador possa abrir o diário. A privacidade é o ponto de partida, não um acrescento posterior.

Idiomas

O Shodia está disponível em finlandês, sueco, norueguês, dinamarquês, estónio, letão, lituano e inglês. Utiliza o idioma do dispositivo quando este é suportado.
