Shodia · Guía de usuario

Guía de usuario

Shodia facilita llevar un diario de entrenamiento completo y fiable y compartirlo cuando lo necesites.

Registrar una sesión

Añade una sesión y registra los datos esenciales: arma, munición, distancia, puntos de impacto y puntuaciones. Las sesiones incluyen una marca de tiempo y se guardan localmente.

Seguir objetivos

Establece tu propio objetivo de visitas. Shodia lleva un recuento continuo para que siempre conozcas tu progreso. Confirma los requisitos de licencia que te correspondan con la autoridad competente. Consulta Exención de responsabilidad para conocer los límites de esta función.

Exportar registros

  • PDF — plantillas específicas de cada país para un resumen de entrenamiento que puedes compartir con autoridades o instructores. Confirma con el destinatario que el resumen es aceptable para tu propósito.
  • CSV — todo tu historial para análisis personales, sin depender de la aplicación.

Las exportaciones se generan cuando las solicitas y solo se comparten con los destinos que eliges.

Bloquear tu diario

Activa el bloqueo biométrico o mediante PIN para que solo tú puedas abrir el diario. La privacidad es el punto de partida, no un añadido posterior.

Idiomas

Shodia está disponible en finés, sueco, noruego, danés, estonio, letón, lituano e inglés. Utiliza el idioma del dispositivo cuando es compatible.
