Shodia · Benutzerhandbuch

Benutzerhandbuch

Shodia macht es einfach, ein vollständiges, verlässliches Trainingstagebuch zu führen und die Aufzeichnungen bei Bedarf weiterzugeben.

Eine Trainingseinheit erfassen

Fügen Sie eine neue Einheit hinzu und erfassen Sie die wichtigsten Angaben: Schusswaffe, Munition, Entfernung, Trefferpositionen und Punkte. Die Einheiten erhalten einen Zeitstempel und werden lokal gespeichert.

Ziele verfolgen

Legen Sie Ihr eigenes Besuchsziel fest. Shodia zählt die Besuche fortlaufend, damit Sie Ihren Fortschritt jederzeit kennen. Bestätigen Sie die für Sie geltenden Erlaubnisanforderungen bei der zuständigen Behörde. Die Grenzen dieser Funktion finden Sie unter Haftungsausschluss.

Aufzeichnungen exportieren

  • PDF — länderspezifische Vorlagen für eine Trainingszusammenfassung, die Sie mit Behörden oder Ausbildern teilen können. Klären Sie mit dem Empfänger, ob die Zusammenfassung für Ihren Zweck anerkannt wird.
  • CSV — Ihr gesamter Verlauf für eigene Analysen, ohne Bindung an die App.

Exporte werden auf Anfrage erstellt und nur an die von Ihnen gewählten Ziele weitergegeben.

Ihr Tagebuch sperren

Aktivieren Sie die biometrische Sperre oder eine PIN, damit nur Sie Ihr Tagebuch öffnen können. Datenschutz ist der Ausgangspunkt, kein nachträglicher Zusatz.

Sprachen

Shodia ist auf Finnisch, Schwedisch, Norwegisch, Dänisch, Estnisch, Lettisch, Litauisch und Englisch verfügbar. Die App übernimmt die Gerätesprache, sofern diese unterstützt wird.
