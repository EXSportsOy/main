Guide d’utilisation

Présentation

SurveyTools regroupe des calculateurs pour déterminer les quantités de cargaison des navires et les opérations de draft survey : interpolation, volume en coin, corrections des réservoirs terrestres et conversions d’unités. Chaque module suit le même principe : saisir les valeurs, toucher Calculer, puis vérifier le résultat.

Utilisation générale

  • Saisissez les valeurs avec le clavier numérique. Choisissez le séparateur décimal dans les paramètres : point ou virgule.
  • Calculer exécute le module sélectionné. Des données manquantes ou invalides empêchent d’obtenir un résultat pertinent.
  • Effacer réinitialise les champs. Certains écrans peuvent conserver les valeurs communes pour accélérer les calculs répétés.
  • Les paramètres peuvent inclure des options d’affichage et de saisie qui modifient l’interface, mais pas les calculs.

Modules

Interpolation →
Interpolation linéaire, à une ou deux variables pour exploiter les tableaux.
Calculateur de volume en coin →
Estime le volume en coin lorsque le navire a une assiette et que le liquide ne touche pas toutes les parois.
Corrections des réservoirs terrestres →
Corrections de dilatation thermique de la robe et de déplacement du toit flottant.
Conversions d’unités →
Conversions de masse volumique et de volume utilisées pour mesurer les cargaisons.
CTL / VCF — présentation →
Utilisation de CTL/VCF dans l’application, sans reproduire le texte de normes payantes.
