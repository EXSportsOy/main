Calculadora de cuña

La calculadora de cuña se usa cuando un buque tiene asiento y el producto del tanque forma una cuña, un triángulo visto de lado. Puede ocurrir con volúmenes pequeños cuando el líquido no toca las cuatro paredes del tanque.

Datos necesarios

  • Calado de popa y calado de proa para obtener el asiento.
  • LBP, eslora entre perpendiculares.
  • Longitud del tanque.
  • Altura de referencia y distancia del mamparo de popa al punto de medición.
  • Sonda observada.
  • Volumen de tabla para la condición correspondiente, obtenido de la tabla del tanque.

Funcionamiento general del cálculo

  1. Calcula el asiento del buque: calado de popa menos calado de proa.
  2. Divide el asiento entre LBP para obtener el factor de asiento.
  3. Calcula una sonda corregida según la geometría del asiento y la posición del punto de medición.
  4. Comprueba si se trata de un caso de cuña e indica cuando no lo es.
  5. Estima el volumen en cuña con el volumen de tabla y la sonda corregida.

Notas prácticas

  • Si LBP = 0, el cálculo no es válido.
  • Sin asiento, cuando el factor de asiento es cero, el efecto de cuña es cero.
  • Asegúrate de que el valor de tabla use la misma referencia y las mismas unidades que los datos introducidos.
