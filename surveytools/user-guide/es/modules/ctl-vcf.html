CTL / VCF — descripción general

Algunos cálculos de SurveyTools necesitan un factor de corrección de temperatura para productos petrolíferos. Se denomina CTL o, de forma más general, factor de corrección de volumen, a veces abreviado VCF.

Uso en esta aplicación

  • Ajustar el volumen entre la temperatura observada y una temperatura de referencia.
  • Apoyar cálculos dependientes, como el desplazamiento del techo flotante (FRC).
  • Apoyar determinadas conversiones de unidades, por ejemplo volumen estándar a barriles en condiciones de referencia.

Buenas prácticas

  • Utiliza SurveyTools como ayuda de cálculo dentro de tu procedimiento habitual.
  • Contrasta los resultados con tus tablas oficiales o sistemas certificados.
  • Ante resultados inesperados, verifica la base de densidad (vacío/aire), la temperatura y el grupo de productos seleccionado.
